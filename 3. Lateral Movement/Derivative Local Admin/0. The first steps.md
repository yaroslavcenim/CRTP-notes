**Find PSRemoting Local Admin Access:**
```powershell
Import-Module Find-PSRemotingLocalAdminAccess.ps1
Find-PSRemotingLocalAdminAccess -ComputerName corp-pc
Find-PSRemotingLocalAdminAccess -ComputerFile C:\test\computers.txt -Verbose
```

**Connect with PSRemoting:**
```powershell
Enter-PSSession -ComputerName corp-pc
```
